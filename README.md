# TCS-Stock-Analysis-
Using python pandas and matplotlib

## Project Description
This project analyzes Tata Consultancy Services stock market data using Python.  
It uses a manually created stock database and performs stock trend analysis, moving average calculation, trading volume analysis, and bullish or bearish trend prediction.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Features
- Creates TCS stock market database
- Calculates daily return
- Calculates moving average
- Finds highest stock price
- Finds lowest stock price
- Finds highest trading volume
- Shows closing price graph
- Shows moving average graph
- Shows volume graph
- Gives bullish or bearish trend
